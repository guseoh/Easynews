# Phase 2 검증 — 완료

검증일: 2026-10-02 (Asia/Seoul)

최신 상태 정정: Phase 3/4 요청에서 사용자가 실제 OpenAI API E2E QA는 **크레딧 미충전으로 보류**라고 안내했습니다. 아래 이전 사용자 확인 보고는 당시 기록으로 남기되 현재 실제 API 검증의 완료 근거로 사용하지 않습니다. Phase 2 구현·자동 검증·Chrome fixture 결과는 유효하며, 실제 API QA는 대기합니다.

## 구현 범위

- 쉽게 설명 / 왜 그런가 / 배경 설명
- 작은 로컬 TypeScript 서버와 `POST /api/explain`
- 선택 문장·제목만 요청 시점에 처리, 답변 일반 텍스트 표시
- loading·error·retry, 타임아웃과 요청 취소
- 기사 전체 분석·기사 추출·관련 기사·장기 저장 제외

## 자동 검증

- `npm run typecheck`: extension·server TypeScript 검사 통과
- `npm run build`: extension 번들·server 컴파일 성공
- `npm test`: extension 9개, server 9개, 총 **18개 통과**
- `npm run start:server`: 실제 시작 성공, `/health` 200, 미설정 `/api/explain` 503 및 설정 안내 확인. 검증 후 서버 종료

서버 테스트는 실제 루프백 HTTP 요청을 사용하고 OpenAI 호출만 mocking합니다. 세 모드별 최소 입력, `store: false`, JSON 스키마, 본문·URL 추가 필드 거부, Origin·확장 ID 제한, 크기 제한, 공급자 오류·rate limit·시간초과·거부·불완전 응답, 클라이언트 종료 시 취소와 동시 요청 제한을 확인합니다.

확장 테스트는 기존 Phase 1의 5개와 설명 요청의 최소 데이터·크기 제한·응답 검증·선택 변경 시 취소·늦은 답변/오류 차단의 4개입니다. 실제 Chrome UI와 답변 품질을 대신 검증하지 않습니다.

## Chrome에서 패널 UI 코드 검증 — 키 없이 수행

사용자 요청에 따라 `node extension/scripts/ui-qa.mjs`로 루프백 테스트 화면을 실행하고 실제 Chrome에서 직접 버튼을 클릭했습니다. 빌드된 `sidepanel.html`·CSS·JS를 그대로 사용했으며 Chrome API와 AI 응답만 테스트용으로 대체했습니다. 입력은 합성 문장뿐이며 외부 AI 서비스나 뉴스 본문을 사용하지 않았습니다.

| 항목 | 결과 |
| --- | --- |
| 명시 요청 | 초기 요청 수 0, 설명 버튼 클릭 때만 요청 발생 |
| 세 모드 | 쉽게 설명·왜 그런가·배경 설명이 각각 해당 모드의 테스트 응답 표시 |
| 최소 입력 | 전송 필드가 articleTitle·mode·selectedText 세 개뿐임을 확인 |
| 안전한 출력 | HTML 태그 형태의 응답도 일반 텍스트로 표시 |
| rate limit | 요청 한도 오류 안내와 재시도 버튼 표시 |
| 수동 재시도 | 오류 해소 후 이전에 선택한 모드로 정상 재시도 |
| 선택 변경 | 이전 답변 제거, 자동 설명 요청 없음 |
| loading | 응답 대기 문구와 세 설명 버튼 비활성화 |
| 기사 이동 | 요청·답변 상태 제거, 취소 후 도착한 응답도 다시 표시되지 않음 |
| 긴 선택 | 2,001자 선택에서 설명 버튼 비활성화 및 길이 안내 |
| 패널 종료 이벤트 | 답변·로딩 표시 제거, 늦게 완료된 응답 차단 |
| 서버 정지 | 실제 로컬 fixture 서버 종료 후 연결 오류·재시도 버튼 표시 |

테스트 종료 후 임시 서버와 테스트 탭을 닫았습니다. 검증 화면은 합성 데이터만 포함하는 `.qa/phase2-ui.png`에 기록했으며 Git에서 제외합니다. 제품 코드의 수정이 필요한 문제는 발견하지 않았습니다. 기존 성공한 18개 자동 테스트는 코드 변경이 없어 반복 실행하지 않았습니다.

이 검증은 **실제 Chrome에서 패널 UI 코드를 실행한 fixture 테스트**입니다. Chrome 확장 권한·Side Panel 자체의 수명·실제 네이버 선택 이벤트·OpenAI 답변 품질을 대신 확인하지 않습니다. 네이버 기사 탭에는 브라우저 도구로 연결했으나 해당 도구가 Chrome의 별도 Side Panel 영역을 제공하지 않아 설치된 패널은 직접 조작하지 못했습니다.
