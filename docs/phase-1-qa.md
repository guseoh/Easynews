# Phase 1 검증

검증일: 2026-10-02 (Asia/Seoul)

## 자동 검증

- `npm run typecheck`: TypeScript 검사 통과
- `npm run build`: 서비스 워커·콘텐츠 스크립트·패널 번들 생성 및 정적 파일 복사 성공
- `npm test`: Chrome API를 mocking한 서비스 워커 테스트 **5개 통과**. 사용자 실행 전 수집 차단, 메시지 검증, 패널 종료 시 삭제, 탭 격리, 늦은 메시지와 이동 간 경합, 오류 처리 확인

Mock 테스트는 실제 Side Panel UI나 Chrome 권한 동작을 검증하지 않습니다.

## 실제 Chrome 확인 상태 — Phase 1 완료

2026-10-02 사용자가 일반 Chrome의 네이버 뉴스 실제 기사에서 수동 QA를 완료했다고 확인했습니다. 다음 항목은 **사용자 수동 검증 통과**입니다.

- Side Panel 표시
- 현재 기사 제목·URL 인식
- 본문에서 선택한 텍스트 전달
- 다른 문장 선택 시 갱신
- 다른 기사 이동 시 이전 임시 데이터 제거
- Side Panel 종료 후 임시 데이터 제거

자동 검사·빌드·테스트와 위 수동 QA를 근거로 Phase 1을 완료 처리합니다. 에이전트의 headless 및 computer-use 자동 검증은 환경 제한으로 완료하지 못했으며, 실제 Chrome 동작의 확인 근거는 사용자의 수동 QA입니다. 기사 본문이나 선택 문장은 QA 기록에 보관하지 않습니다.

## 수동 확인 목록

아래는 후속 회귀 검증용 목록입니다. 위에서 명시한 핵심 항목 외의 세부 항목은 별도 수동 검증 결과가 아직 없으며, 자동 테스트에서 확인한 범위와 구분합니다.

| 항목 | 확인 방법 |
| --- | --- |
| MV3 로드 | `extension/dist` 로드 후 확장 오류가 없는지 확인 |
| 패널 열기 | 일반 기사 탭에서 확장 아이콘 실행 후 원문 옆 패널 표시 |
| 기존 선택 | 아이콘 실행 전 문장 선택 → 제목·URL·선택 문장 표시 |
| 선택 갱신 | 패널 열린 상태에서 다른 문장을 마우스 또는 키보드로 선택 |
| 패널 포커스 | 패널 클릭 후 마지막 선택 내용 유지 |
| 반복 실행 | 같은 탭에서 재실행 후 선택 감지가 정상 동작 |
| 탭 이동 | 다른 탭에서 이전 기사 내용이 남지 않고 아이콘 실행 안내 표시 |
| 페이지 이동 | 링크 이동·새로고침 후 이전 상태 삭제; 아이콘 재실행 시 새 페이지 표시 |
| 패널 종료 | 패널을 닫고 재실행했을 때 이전 선택 상태가 남지 않는지 확인 |
| 접근 제한 | `chrome://version`에서 이해할 수 있는 오류 안내 |
| 입력창 제외 | 입력창·편집 영역 선택이 패널에 수집되지 않는지 확인 |
| 안전한 표시 | HTML 모양의 문장이 HTML 요소로 해석되지 않는지 확인 |
| 긴 선택 | 8,000자 이상 선택 시 잘림 안내와 제한 확인 |
| 세션 정리 | 탭 닫기·확장 재로드·Chrome 재시작 후 상태 삭제 |

네이버 뉴스·한국경제·매일경제·연합뉴스에서 제목·URL·선택 흐름을 각각 확인합니다. 본문 추출은 Phase 3, AI 설명은 Phase 2, 추천 품질은 Phase 4 이후 실제 API와 함께 검증합니다.
