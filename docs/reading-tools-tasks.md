# 문장 이해 도구 — Task 순서

기존 가독성·설명 버튼·빈 화면·원문 복귀 개선 위에 아래 순서로 추가한다.

| 순서 | 기능 | 구현 내용 | 상태 |
|---|---|---|---|
| Task 1/6 | 빠른 추가 질문 | 더 쉬운 말로 / 일상적인 예로, 기존 질문 API 사용 | 구현 |
| Task 2/6 | 앞뒤 문맥 보기 | 추출된 주변 문맥 펼치기, 일치하는 선택 문장 강조, 미추출 안내 | 구현 |
| Task 3/6 | 문장 구조 풀기 | 누가 / 무엇을 / 조건과 관계 / 확인할 수 없음 구분 | 구현 |
| Task 4/6 | 문장 맞춤 질문 | 설명과 같은 요청에서 최대 2개 질문 생성, 클릭하여 질문 | 구현 |
| Task 5/6 | 원문 근거 구절 | 선택·주변 문맥과 일치하는 인용 최대 3개, 일반 설명 인용 제외 | 구현 |
| Task 6/6 | 선택 문장 배경 기사 | 기사 범위와 선택 범위 구분, 선택 범위에서는 배경만 표시 | 구현 |

## 데이터와 동작 경계

- 선택 문장 2,000자, 주변 문맥 1,600자, 질문 300자 제한을 유지한다. 기사 전문·이전 AI 답변·질문 이력을 요청에 넣거나 저장하지 않는다.
- 질문 제안·인용 데이터는 설명 본문 뒤의 별도 영역으로 생성하고 서버가 분리한다. 스트리밍 중에도 이 데이터는 본문에 노출하지 않는다. 부가 데이터가 없거나 잘못되면 설명 본문만 표시한다.
- 인용은 서버와 확장이 원문 문자열 일치를 검사한다. 문자열 일치는 AI 설명의 정확성이나 실제 사실을 검증한 것이 아니다. 인용이 없으면 안내한다.
- 문장 구조는 원문에 명시된 주체·행동·관계만 설명하도록 요청한다. 생략된 내용을 추측해 채우지 않는다.
- 기사 범위 검색은 기존 metadata·도입부 요청을 유지한다. 선택 범위 검색은 제목·URL 등 metadata와 선택 문장·주변 문맥만 사용하며 도입부는 보내지 않는다.
- 선택 범위는 직접적인 이해 도움을 확인한 배경 기사만 반환한다. 날짜·출처·URL 검증을 유지한다. AI 관계 판정 실패 시 기사 전체 규칙으로 배경을 추정해 채우지 않는다.
- 선택 범위에서 문장·주변 문맥·검색 범위가 바뀌면 검색을 취소하고 결과를 제거한다. 선택·기사 변경, 연결 변경, 패널 종료 시 질문 제안·인용·답변도 정리한다.

## 검증 범위

자동 검증은 확장·서버 타입 검사, 빌드, 전체 회귀 테스트와 스트림 분리·인용 일치·검색 범위 테스트를 사용한다. 브라우저 모의 응답으로 UI를 확인하는 것과 실제 AI 모델의 질문·구조·인용·검색 품질 확인은 구분한다. 실제 Plus 품질 검증은 별도로 필요하다.

이번 작업의 타입 검사·빌드·전체 회귀 테스트는 통과했다. 총 152개 중 151개 통과, Windows 환경의 기존 POSIX 파일 권한 검사 1개 건너뜀, 실패 0개다. Chrome 320px 로컬 화면에서 6개 기능과 문장 변경 시 답변·질문·인용·검색 결과 제거를 모의 응답으로 확인했다.
